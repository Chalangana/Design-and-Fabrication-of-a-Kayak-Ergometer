# Design-and-Fabrication-of-a-Kayak-Ergometer
In the ergometer project, we designed the mechanical system for a kayak ergometer. The base was constructed using woodworking techniques. The mechanism incorporated two one-way clutch bearings, ropes, a flywheel, seat, springs, and pulleys. Cushions were added to the bottom of the wooden base to maintain balance. This was a two-member project, where both of us were involved in designing the structure using SolidWorks and carrying out the manufacturing process.
